Make ``shared-release-schedule`` bump levels configurable through ``minor-fragments`` and ``major-fragments``, and fragment discovery through ``newsfragments-dir`` and ``newsfragments-extension``, all taking their previous behaviour as defaults.
Previously only ``newsfragments/*.feature.rst`` raised the minor and nothing raised the major, so a ``break`` fragment released as a patch, and a repository keeping markdown fragments or using towncrier's ``directory`` setting was invisible to the planner. On a pre-1.0 project list the breaking type under ``minor-fragments`` and leave ``major-fragments`` empty.
With ``newsfragments-required`` enabled an empty newsfragments directory still skips quietly, but a missing directory, or fragments found only under another extension, now fail the run, as such a repository would never release.
